**Convert an image into another image.**

This works by searching through the image, swap neigber pixels and checks which decreases cost (which is the difference between a pixel in image 1 and image 2 the most).

To run:
    `compile g++ main.cpp -lsdl2 -lsdl2_image -O3`
     Make sure you have gif.h installed and in the same directory.
     Then type in `a` and you will recieve more instructions.
